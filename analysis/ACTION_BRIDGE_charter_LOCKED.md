## The question, reduced to what the registry already fixes

The corpus owns two actions of the same form, tension times area over c (GRV-093):
  hbar  = T0 [ l_q^2 / (4 pi alpha) ] / c          (R1; l_q entered through the alpha relation)
  A*    = T0 [ (3 beta / (0.23 chi)) a h ] / c      (GRV-092; derived; the snap action)
and their ratio n_q = A*/hbar carries exactly one power of the lattice spacing a while hbar's
area carries zero (GRV-094, the one-power theorem). So in this corpus "derive hbar from the
snap action" means exactly one thing: derive the COUNT

  N = hbar / A* = (0.23 chi / 3 beta) * l_q^2 / (4 pi alpha a h)

from a registered mechanism that does not consume hbar, alpha, l_q or m_e. Because N depends
on a, a derived N is an equation for a: Task 1 and Task 2 are the same equation (the prompt's
"the mass question and the scale question fused"). A bridge that fixes N fixes the absolute
scale, and acceptance test (d) then follows or fails at once against R2 (a = 8 l_P within
sqrt(D), GRV-095) and R4 (a < 1e-16 m).
